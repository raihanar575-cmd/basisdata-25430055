## 4. Konfigurasi MariaDB

Pemeriksaan versi MariaDB dan akun yang digunakan dilakukan dengan perintah:

```sql
SELECT VERSION(), CURRENT_USER();
```

```text

CURRENT_USER(): root@localhost
```

Mode SQL diperiksa menggunakan:

```sql
SELECT @@sql_mode;
```

```text

```
